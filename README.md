# Portfolio Website

Personal portfolio website  menggunakan Tailwind CSS untuk menampilkan informasi diri, skill, dan proyek yang telah dibuat.

### External Resources

* **Poppins** — Google Fonts
* **Font Awesome** — icon library
* **AOS (Animate On Scroll)** — animation library
* **Typed.js** — typing animation library

Beberapa referensi kode, desain, maupun asset juga diperoleh dari **repository GitHub dan sumber lain di internet**. Jika terdapat kode atau asset yang berasal dari pihak lain, sumber aslinya akan dicantumkan sebagai bentuk apresiasi dan atribusi.
